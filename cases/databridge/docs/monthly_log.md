# Восьмимесячный сценарий работы проектного аналитика

> **Смоделированная ретроспектива, а не дневник фактически выполненной работы.** Компания и временные отметки созданы для обучения. Данные по месяцам: [CSV](../data/monthly_delivery_simulated.csv).

|---|---|---|---|

## Модельный план-факт

`planned_deliverables` — запланированные в отдельном месяце проверяемые результаты, `accepted_deliverables` — условно принятые, `deferred_deliverables` — отложенные на будущие периоды; каждый месяц они взаимно исключаются и суммируются в план.

`planned_hours` и `actual_hours` — полностью синтетические величины **для упражнения по проектному контролю**. Они **не** получены из GitHub и не являются фактическими трудозатратами пользователя или любой компании.

По всей модели: 65 запланированных, 59 принятых, 6 отложенных результатов; 696 плановых и 722 условно фактических часа. Часть отложенных результатов требует отдельного решения; 90,8% принятия плановых поставок **не означает** завершение проекта на 90,8%.
