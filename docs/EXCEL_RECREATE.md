# Excel: как воспроизвести отчёт

В `Project Dashboard.xlsx` данные взяты из `data/github_issues_snapshot.csv` и `data/github_prs_snapshot.csv` **на 13 октября 2026 года**. Сводные KPI на листе «Dashboard» рассчитываются формулами `COUNTIF/COUNTA`; данные и визуализация не являются live-подключением к GitHub.

1. Запусти `python scripts/refresh_from_github.py`, если нужен новый снимок.
2. Затем `python scripts/build_reports.py` и `python -m unittest discover -s tests -v`.
3. В Excel обнови листы `Issues` и `PRs` из соответствующих CSV через **Данные → Из текста/CSV**. Не смешивай Issues и PR в одну сущность.
4. Проверяй, что формулы на Dashboard охватывают весь импортированный диапазон. Встроенный xlsx — зафиксированный отчёт; если строк стало больше, расширь диапазоны формул.
5. Из `reports/daily_activity.csv` обнови тренд и диаграмму по календарным дням.
6. Если будешь вводить даты по плану или оценки задач, сохраняй источник/дату согласования и не подставляй придуманную базу.

Для интервью: объясни разницу между `closed_share` и реальной готовностью продукта. Второй показатель нельзя получить корректно без оценки веса работ или управленческого baseline.
