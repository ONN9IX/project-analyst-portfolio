# Проверка материалов портфолио

Дата проверки: 19 октября 2026 года. Аналитические данные остаются историческим срезом на 13 октября 2026 года.

- Сохранены все 45 исходных файлов архива и их относительные пути. Дополнительно добавлены два изображения для предпросмотра Excel и этот отчёт.
- README и относительные ссылки проверены. Все 232 ссылки на исходные Issues и PR сопоставлены с действующими объектами публичного GitHub API: совпали номера, типы объектов и даты создания.
- CSV содержат 137 обычных Issues и 95 PR. Три штатных автоматических теста проходят. Issues и PR считаются отдельно.
- В обеих книгах Excel проверены формулы, сохранённые значения, входные CSV и отсутствие ошибок ячеек. Основные листы визуально просмотрены; их изображения включены в README. XLSX не пересохранялись при проверке.
- SQL-схема и семь запросов разобраны PostgreSQL-парсером pglast. Схема и все запросы выполнены на CSV в DuckDB; только в проверочной копии запроса 6 добавлен UNNEST для различия синтаксиса generate_series. PostgreSQL-сервер для выполнения не запускался.
- Обе версии DOCX отрендерены и визуально проверены. PDF пересобраны из тех же DOCX, проверены визуально и программно: каждая версия занимает одну страницу, ссылки на GitHub и портфолио активны.
- В резюме нет вымышленного трудоустройства, работодателя или коммерческого стажа. Smart Garden обозначен как собственный IT-проект. Метрики относятся ко всему исходному проекту и не приписываются личной выработке. Публичный контакт — GitHub; неизвестные телефон, город и почта не добавлены.
- Оба исходных графика проверены визуально. Excel и Word доступны для скачивания; PDF, Markdown, SQL и PNG доступны в интерфейсе GitHub с учётом возможностей его встроенного просмотра.
- Smart Garden использован исключительно через чтение публичного API. Изменений в исходном репозитории не выполнялось.

Проверка подтверждает согласованность материалов и доступность исходных объектов. Она не подтверждает коммерческий стаж, уровень владения инструментами на собеседовании или текущий статус продукта после даты среза.
