# RACI — учебное предложение

Этот RACI **не утверждён участниками Smart Garden** и не следует из назначения Issues. Это иллюстрация аналитика: как можно распределить согласование и исполнение задач, если команда примет соответствующие роли.

- **R** — непосредственно выполняет работу.
- **A** — принимает решение и отвечает за результат (один на задачу).
- **C** — консультирует.
- **I** — информируется.

| Процесс | Владелец продукта | Разработчик | QA/ревьюер | Аналитик проектов |
|---|---|---|---|---|
| Согласование scope и приоритетов | A | C | C | R |
| Декомпозиция и оценка задачи | A | R | C | C |
| Разработка функциональности | I | A/R | C | I |
| Проверка критериев приёмки | A | C | R | C |
| Реестр рисков и статус-отчёт | A | C | C | R |
| Go/no-go пилота и персональных данных | A | C | C | R |

Последняя строка — управленческий процесс. Решение о реальной обработке персональных данных требует самостоятельных юридических и технических проверок, которыми таблица RACI не заменяется.
